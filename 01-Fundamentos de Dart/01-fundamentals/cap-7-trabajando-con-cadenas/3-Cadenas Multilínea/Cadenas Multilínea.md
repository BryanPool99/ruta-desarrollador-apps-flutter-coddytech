# Cadenas Multilínea

Crear cadenas de varias líneas usando comillas triples:


```dart
String poem = '''
Roses are red,
Violets are blue,
Dart is awesome,
And so are you!
''';
```
Imprimir cadenas de varias líneas:
```dart
print(poem);
```
Usar interpolación de cadenas dentro de cadenas de varias líneas:
```dart
String message = '''
Event: $eventName
Date: $date
Location: $location
''';
```
