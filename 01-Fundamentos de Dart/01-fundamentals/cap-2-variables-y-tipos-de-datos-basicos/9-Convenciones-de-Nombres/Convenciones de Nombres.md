# Convenciones de Nombres

Las convenciones de nomenclatura de Dart hacen que el código sea legible y consistente:

Usa camelCase para variables:
```dart
String firstName = 'John';
int userAge = 25;
double accountBalance = 100.50;
bool isLoggedIn = true;
```

Comienza los nombres de variables con letras o guiones bajos:
```dart
var name = 'Dart';
var counter = 1;
```

Usa nombres significativos y descriptivos:
```dart
var temperatureFahrenheit = 75.5;
```

Usa lowerCamelCase para constantes:
```dart
const pi = 3.14159;
const maxUsers = 100;
const baseUrl = 'https://api.example.com';
```
