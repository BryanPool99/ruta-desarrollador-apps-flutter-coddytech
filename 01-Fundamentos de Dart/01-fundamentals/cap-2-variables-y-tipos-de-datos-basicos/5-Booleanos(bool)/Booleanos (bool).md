# Booleanos (bool)

Los booleanos (tipo bool) tienen solo dos valores: true o false. Representan condiciones sí/no en los programas.

```dart
bool isRaining = true;
bool isCompleted = false;
```

Los valores booleanos se escriben sin comillas y se pueden reasignar:

```dart
bool isCompleted = false;
isCompleted = true; // Cambiar el valor
```
