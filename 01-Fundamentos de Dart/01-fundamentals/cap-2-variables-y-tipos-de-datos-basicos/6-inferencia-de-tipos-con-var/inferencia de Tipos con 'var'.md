# Inferencia de Tipos con 'var'

Usa var para inferencia de tipos - Dart determina automáticamente los tipos de variables a partir de los valores asignados:

```dart
var name = 'Dart Programmer';  // Inferido como String
var age = 25;                   // Inferido como int
var price = 19.99;              // Inferido como double
var isAvailable = true;         // Inferido como bool
```
