# ¿Qué son las Variables?

Las variables almacenan datos en tu programa. Cré​alas especificando el tipo, el nombre y el valor:

```dart
String name = 'Dart Programmer';
```

Las variables se pueden referenciar y modificar en todo el código:

```dart
String language = 'Dart';
print('I am learning ' + language);
language = 'Dart programming';
print('I am learning ' + language);
```
