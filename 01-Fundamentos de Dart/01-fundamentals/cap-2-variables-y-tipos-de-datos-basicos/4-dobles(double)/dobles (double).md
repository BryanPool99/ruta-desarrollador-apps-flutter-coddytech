# Dobles (double)

El tipo double almacena números con puntos decimales:

```dart
double price = 19.99;
```

Los valores de tipo double se pueden usar en cálculos y reasignar:

```dart
double temperature = 72.5;
temperature = 75.8;  // Reasignar valor

double increase = 2.5;
double newTemperature = temperature + increase;  // Combinar doubles
```
