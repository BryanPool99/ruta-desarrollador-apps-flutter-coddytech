# La sentencia 'else if'

La sentencia else if en Dart permite verificar múltiples condiciones en secuencia cuando necesitas manejar más de dos resultados posibles.

Sintaxis básica:
```dart
if (condition1) {
  // Code to execute when condition1 is true
} else if (condition2) {
  // Code to execute when condition1 is false and condition2 is true
} else {
  // Code to execute when both condition1 and condition2 are false
}
```
