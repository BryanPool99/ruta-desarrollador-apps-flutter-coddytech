# NOT Lógico

El operador lógico NOT (!) invierte los valores booleanos, convirtiendo true en false y viceversa.

```dart
bool isRaining = true;
bool isNotRaining = !isRaining;

print('Is it raining? $isRaining');        // true
print('Is it not raining? $isNotRaining'); // false
```

El operador NOT es útil para verificar condiciones negativas y puede combinarse con otros operadores lógicos.
