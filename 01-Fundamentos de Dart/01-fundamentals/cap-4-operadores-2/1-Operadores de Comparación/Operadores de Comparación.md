# Operadores de Comparación
Los operadores de comparación en Dart devuelven valores booleanos para la toma de decisiones:

== - igualdad
!= - desigualdad
> - mayor que
< - menor que
>= - mayor o igual que
<= - menor o igual que

```dart
void main() {
  int a = 10;
  int b = 10;
  bool areEqual = a == b;
  
  print('Is $a equal to $b? $areEqual');
}
```
