# Atajos de Asignación

Los atajos de asignación combinan operadores aritméticos con la asignación para modificar variables de forma concisa:

### Asignación de suma (+=)

```dart
score += 5;  // Equivalente a: score = score + 5;
```
### Asignación de resta (-=)

```dart
lives -= 1;  // Equivalente a: lives = lives - 1;
```
### Asignación de multiplicación (*=)

```dart
points *= 2;  // Equivalente a: points = points * 2;
```
### Asignación de división (/=)

```dart
price /= 2;  // Equivalente a: price = price / 2;
```
