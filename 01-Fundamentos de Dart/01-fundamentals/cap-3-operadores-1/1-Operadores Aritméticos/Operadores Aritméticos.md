# Operadores Aritméticos
Dart admite cuatro operadores aritméticos básicos:

- + para la suma
- - para la resta
- * para la multiplicación
- / para la división

```dart
int num1 = 10;
int num2 = 5;
int sum = num1 + num2;        // 15
int difference = num1 - num2;  // 5
int product = num1 * num2;     // 50
double quotient = num1 / num2; // 2.0
```

Puedes combinar los tipos int y double en operaciones aritméticas:

```dart
int intValue = 5;
double doubleValue = 2.5;
double result = intValue + doubleValue; // 7.5
```
