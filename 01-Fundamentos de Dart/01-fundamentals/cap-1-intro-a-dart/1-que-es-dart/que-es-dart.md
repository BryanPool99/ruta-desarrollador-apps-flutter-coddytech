# ¿Qué es Dart?
Dart es un lenguaje desarrollado por Google que impulsa Flutter para el desarrollo de aplicaciones multiplataforma.

Una estructura sencilla de un programa en Dart:

```dart
void main() {
  print('Hello, Dart!');
}
```

Entre sus características principales se incluyen la orientación a objetos, el tipado flexible y la seguridad frente a valores nulos.
