# Comentarios de código

Comentarios en Dart:

- Notas para humanos: Dart las ignora
- Pueden desactivar código temporalmente sin borrarlo

Comentario de una sola línea:

```dart
// Esto es un comentario
print('Hello!'); // Comentario después del código
```

Comentario multilínea:

```dart
/* Esto es un
   comentario multilínea */
```

Desactivar código:

```dart
// print('This will NOT run');
print('This will run');
```
