# Imprimir salida
La función print() de Dart muestra información en la consola:

```dart
void main() {
  print('Hello, Dart!');
}
```

Múltiples sentencias print se muestran en líneas separadas:

```dart
void main() {
  print('First line');
  print('Second line');
  print('Third line');
}
```

El texto dentro de las comillas distingue entre mayúsculas y minúsculas.
